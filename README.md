# TGM Accounting & Auditing — React Web Application

Rewritten as a modern React application with TypeScript and Vite, preserving the complete design system, typography, animated skyline, interactive corridor map, partner profiles, and 8 dedicated service lines for TGM Accounting & Auditing LLC.

## Features

- **Home (`/`)**:
  - Desert-to-skyline interactive CSS animation with rising towers, Burj Khalifa silhouette, crane, and sun.
  - "Where owners call us" diagnostic entry points.
  - 8 core service lines with status tagging and direct routing.
  - UAE–Africa Corridor schematic map linking Dubai, Tanzania (TRA), Zambia (ZRA), and Mozambique (AT).
  - Partner highlights and 4-step client engagement workflow.
- **Services (`/services/:slug`)**:
  - Accounting & Bookkeeping (`/services/accounting`)
  - UAE Tax: VAT & Corporate Tax (`/services/uae-tax`)
  - Finance Health Check (`/services/finance-health-check`)
  - Fractional CFO (`/services/fractional-cfo`)
  - Controls & Automation (`/services/controls-automation`)
  - Funding & Restructuring Advisory (`/services/funding-restructuring-advisory`)
  - UAE–Africa Corridor Finance (`/services/africa-corridor`)
  - Business Setup in Dubai (`/services/business-setup`)
- **Partners (`/partners`)**:
  - CA Yogesh Trivedi (Founding Partner · Finance review & Fractional CFO) with career timeline and operating results across UAE and East Africa.
  - Anil Chowhan (Partner · Banking & capital readiness) with 19 years in UAE SME banking.
- **Contact (`/contact`)**:
  - Office location in Atrium Centre, Al Mankhool, Dubai with Google Maps link.
  - Direct email, phone, and WhatsApp communication channels.
  - Interactive call preparation inquiry form.
- **Accessibility & Design Tokens**:
  - Fraunces serif display, Manrope sans-serif body, IBM Plex Mono numeric styling.
  - Keyboard accessible skip-to-content and sticky navigation.
  - WhatsApp floating quick-action button.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Routing**: React Router v6
- **Styling**: TGM Design System Tokens with vanilla CSS variables and responsive clamping
